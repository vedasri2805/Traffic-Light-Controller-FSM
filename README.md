# Traffic Light Controller Using FSM

## About the Project
A simple traffic light controller designed using Verilog HDL and a Finite State Machine (FSM).

## Technologies Used
- Verilog HDL
- EDA Playground
- Icarus Verilog

## Project Files
- `design.sv` – Traffic light controller design.
- `testbench.sv` – Testbench for simulation and verification.

## Features
- Controls Red, Yellow and Green traffic light signals.
- Uses FSM-based state transitions.
- Simulates traffic light sequences.
- Uses a testbench to verify the design.

## Simulation
The project was developed and simulated using EDA Playground.
